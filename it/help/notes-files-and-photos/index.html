Note, file e foto

Tieni i dettagli dove andrai a cercarli: sulla scheda stessa, o come nota nel giorno.

2 min di lettura Aggiornato il 1º novembre 2026 iPhone iPad Mac
1

Apri la scheda

Tocca una scheda qualsiasi sulla bacheca. Sotto i suoi dati trovi Aggiungi nota e Aggiungi file o foto.

1Scrivi una nota2Allega qualcosa
2

Prendilo da dove vuoi

Fai una foto a un biglietto di carta, oppure scegli un PDF da File o uno screenshot dalla Libreria foto. Resta sulla scheda.

1Fotocamera, File o Foto
3

Una nota per tutto il giorno

Per qualcosa che non è un luogo, come Portare contanti, tocca il pulsante della nota in basso. Diventa una scheda gialla nel giorno.

1La tua nota2Nuova nota
1

Note e file sul Mac

Fai clic su una scheda per aprirla: anche la sua nota e i suoi file sono lì. Per una nota nel giorno, usa il pulsante della nota in fondo alla colonna, oppure la tastiera:

⌃⌘NNuova nota ⌘NNuova scheda

Buono a sapersi

Allega un biglietto o una prenotazione e Trovelo compila il codice di prenotazione quando lo trova.

File e foto si sincronizzano con gli altri tuoi dispositivi tramite il tuo iCloud.
