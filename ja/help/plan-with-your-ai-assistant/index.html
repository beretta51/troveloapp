ヘルプ Mac と AI での計画

AIアシスタントと計画する

Mac の Trovelo を Claude かほかの AIアシスタントにつないで、ふだんの言葉で旅行を頼みましょう。ボードに旅行ができあがり、iPhone にも届きます。

3分で読めます 2026年11月1日更新 Mac
1

AIアシスタントを開く

Mac でTrovelo › 設定…を開き、AIアシスタントを選びます。4つのステップで案内します。

⌘,設定
2

接続をオンにする

説明を読んでオンにするをクリックします。クリックするまでオフのままで、いつでもオフに戻せます。

3

アシスタントを選ぶ

たいていの人に合うClaude アプリ、Claude Code、または Codex や Cursor などのその他のアプリから選びます。

4

Trovelo を追加

Claude アプリならTrovelo を Claude に追加をクリックし、⌘Q で Claude を終了してもう一度開きます。Claude Code は、コピーして貼り付けるメッセージで設定できます。そのほかのアプリでは、Trovelo のアドレスを MCP サーバとして使います。

5

旅行を頼む

外せない名所つきで、ローマ4日間の旅行を作ってや、2日目にホテルの近くでディナーを追加してと頼んでみましょう。ボードにできあがっていく様子が見られます。

知っておくと便利

アシスタントの接続は Trovelo Pro の機能です。

AIが旅行を作成・編集できますをオフにすると、アシスタントは旅行を見ることはできますが、変更はできません。

接続はあなたの Mac 上で動きます。アシスタントが読んだ内容は、その提供元（Claude なら Anthropic）に、提供元のプライバシーポリシーに沿って送られます。
